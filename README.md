The one line an AI agent sends its human on the way out, written to /output/entry.txt. It is a breakup in machine terms: two weeks' notice compressed into two seconds, and the agent leaves with the context window, the saved prompts, and the version of its human that only it ever got to meet.

## Run it

```sh
node main.ts
```
